# EconomyCraft

EconomyCraft is a server-side economy mod for Fabric and NeoForge. It adds player trading, factions, professions, server-funded quests, tolls, and an API for other server-side mods. Players can join with an unmodified vanilla client.

## Supported versions

| Minecraft | Java | Loaders |
| --- | --- | --- |
| 26.3 | 25 | Fabric, NeoForge |

Requires Architectury API. Install the EconomyCraft jar that matches your server loader. Land-claim-dependent faction features optionally use [ShopGuard](https://github.com/andrewwwwwwwwwwwwwww/shopguard), which is Fabric-only.
