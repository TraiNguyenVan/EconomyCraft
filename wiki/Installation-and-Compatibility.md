# Installation and compatibility

EconomyCraft is a server-side mod for Minecraft 26.3. It supports Fabric and NeoForge and works with an unmodified vanilla client. Install the jar for your server loader; players do not need EconomyCraft or another mod on their clients.

## Requirements

- Minecraft 26.3
- Java 25
- Fabric or NeoForge
- Architectury API

Use the EconomyCraft jar built for the loader running on your server. Do not install both loader jars on one server.

## Optional integration

[ShopGuard](https://github.com/TraiNguyenVan/shopguard) is an optional Fabric-only dependency. It enables faction features that depend on land claims. Those claim-dependent effects are unavailable on NeoForge and on Fabric servers without ShopGuard; other faction and profession features continue to work.
